# Parameter Set 与自定义主控

**Parameter Set。** 从负责该物理量的模块发布输入或输出，或以 Workbench 支持的方式绑定对象属性。几何尺寸、网格分段、CFX 表达式与求解输出分别记录名称、单位、绑定对象和更新时机。在 WBJN 中用 `Parameters.GetAllParameters()` 枚举实际发布项，从对象确认 ID、方向和单位。独立 Tcl 或 Python 变量如要随设计点变化，必须显式建立参数到脚本输入的传递，再回读本次生效值。

在授权的设计点或工程副本上改变一个代表性输入，更新受影响的单元，回读尺寸、网格层数或 CFX 边界值等直接证据。比如油膜间隙改变，应验证几何、生成网格和求解所用间隙属于同一设计点；仅转速改变，通常只需更新 CFX 设置和求解。涉及多个设计点且用户需要逐一打开云图时，启用所需的设计点数据保留，逐点核对结果路径；最后交付约定的当前设计点。用户只要参数化建模时，验证执行到其指定阶段。

**自定义逻辑。** 先把需求写成“当前状态 → 实际测量 → 判定 → 下一步动作”，再把它落实到本次 WBJN。保存循环索引、输入快照、结果来源和接受/拒绝原因，避免把失败或上一轮的值用于下一步。按用户的物理定义处理符号、单位、积分区域、力矩轴与参考点；稳态、末时刻、时间平均分别取值。

- 若要求“扫描转速，某瓦温度超过上限就停止”，在每个已收敛工况读取这块瓦的指定温度统计量，按用户给定的比较符比较，记录首次越限工况并按要求停止。明确取最高温还是平均温；回读失败时单独报告。
- 若要求“调两个变量直到力平衡”，按给定力分量定义残差。使用 Newton 时由相同基准状态分别扰动各变量，形成带单位的雅可比分量，再更新受限的下一组变量。区分数值扰动与已接受工况，记录内层求解质量与外层残差，保留最终接受状态的结果。初值、扰动、容差和停止规则由算例决定。
- 若用户给出其他公式、分支、重启或数据输出要求，直接实现指定逻辑。外部数值程序可处理 Workbench 解释器不支持的库，主控负责调用、错误处理及接受结果；求解顺序与算法控制仍由本次 WBJN 管理。
